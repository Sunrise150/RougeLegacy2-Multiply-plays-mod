### HKMP 核心
- C/S 星型拓扑，自研 UDP + BouncyCastle DTLS；客户端进程也持有 NetServer（嵌入式 listen server）；另有独立 HKMPServer.exe。
- 玩家同步=状态广播（差值检测，朝向压 1 bit）；插值被 `#define no_interpolation` 关闭，实际是吸附式。
- **动画**：tk2dSpriteAnimator 事件 → `AnimationClip` 枚举 ID + Frame + bool[] 特效位 → 接收端用本地预制体 FSM 重放 VFX（`FireballBase`）。法术同步是"事件+本地重放"而非逐帧参数。
- **逐房间 SceneHost 选举 + 自动移交**：首个进房者为 host，离场/断线立即 `SetSceneHostTransfer`；持久状态只有 host 能改（`IgnoreSceneHost` 门控）。→ 对"主机倒地后触发器失效"是结构性答案。
- 进房"快照 + 缓冲门控 + 附加场景 lateLoad"，非冻结等待。
- 实体主机权威 + FSM 快照差分；机关做成组件（Rotation/Velocity/FlipPlatform/HazardRespawn），差值检测发可靠小包。
- 消息按粒度分可靠/非可靠（PlayerUpdate 非可靠，Save/Death/进房可靠），ACK 位图 + MTU1200 + 17/50ms 拥塞控制。
- **无观战、无房间锁、无相机跟随**。PlayMaker FSM 整套不可移植。
- 关键文件：HKMP/Animation/AnimationManager.cs、HKMP/Game/Server/ServerManager.cs、HKMP/Game/Client/Entity/{Entity,EntityManager,EntityProcessor,Component}、HKMP/Networking/。

### TUNIC seamless coop 核心
- BepInEx6 IL2CPP + LiteNetLib 1.2；主机(玩家0)中继原始字节，relay server 只做 NAT 打洞不承载流量。
- "无缝"真相：不是世界合并，是**离散场景 + 稳定跨机 ID + 单写者权威 + 显隐门控 + 共享世界状态 + join code/NAT 打洞体验**。不同场景 puppet 直接 `SetActive(false)`。

- **跨场景传送三重门闩**（Regroup.cs）：scene 名一致 + sceneNameToLoad 一致 + ≥3s + 稳定 1.5s 后才 Teleport；必须有 entry portal 否则宁可不传；落地用 NavMesh/射线吸附 + 临时关 CharacterController。
- **死亡/观战**：致命伤改倒地（留 1hp），全员倒下才真死；观战相机用"先撤销原生相机位移 → orig → 再加回"的对称 hook 避免累积；F2 爬行、队友扶起；离屏箭头标记。
- 敌人按距离单写者所有权 + 接管/释放（Capture/Release）；金币 owner 编进 id 高位 + exactly-once claim。
- 子系统 Guard 隔离，连续 30 次异常单独禁用该子系统。

## 架构重构 v3.0.0（第一阶段：世界驱动权可移交，解决"主机倒地全停摆"）

## v3.0.5：法术动态动画/特效——参照 HKMP 重设（参考 trash）

**根因**（不是调参能解）：v3.0.2 的 AbilityFx 只重放动画状态 hash，特效仍指望分身 Animator 上的
EffectTriggerAnimBehaviour 二次触发，而它会被三件事吞掉：①PlayerSync 把分身 Animator 加进
EffectManager 全局禁用列表（AnimatorEffectsDisabled=true 直接 return）；②AnimBehaviourCondition
依赖 Animator 参数，Trigger 网络传不了（Unity 不暴露）；③离屏/状态机条件。= HKMP 当初为每类
clip 单写 IAnimationEffect 主动 Play VFX 的同一个坑。
