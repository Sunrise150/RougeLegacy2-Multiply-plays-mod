# Rogue Legacy 2 竞速联机 Mod（RL-Mod）

基于 BepInEx + Harmony 的 Rogue Legacy 2 多人竞速模组。最多 **4 人**（1 主机 + 3 客机）在同一张地图上比拼：要么比谁先打死终点 Boss（比用时），要么比谁积分更高（比得分）。

当前版本：**v1.6.1**

## 功能一览

- **同一张地图**：主机把世界地图（房间布局）完整同步给所有客机，大家探索的是同一座城堡。
- **规则同步**：新周目（NG+）等级、最高通关数、全部累赘（Burden）等级自动同步，双方挑战难度一致。
- **互相可见**：实时位置/朝向/动画同步（20Hz 位置 + 10Hz 动画 + 事件型状态包），倒地、复活状态互相可见。
- **两种赛制**：
  - **比用时**：先打死终点 Boss 者胜，每次死亡加时（默认 60 秒/次）。
  - **比得分**：打死终点 Boss 即结算，比总分（探索 +25 / 杀怪 +3 / Boss +300 / 遗物 -50 / 死亡 -100 / 每分钟衰减 -20，均可调）。
- **大厅与就绪**：选好终点后全员准备、全员进入世界才自动开跑（3 秒倒计时）。
- **完赛宽限**：第一名到达终点后，其他人还有 60 秒（可调 0~600）跑完，超时算未完成。
- **断线自动重连**：掉线后自动重连（最长 45 秒），主机保留掉线玩家槽位 90 秒（可调），分数/用时不清零。
- **死亡立即复活**：竞速中原地复活（回满血 + 1.5 秒无敌），不进观战；非竞速阶段死亡则进入倒地观战。
- **终点 Boss 自定义**：8 个 Boss 任选（拉麦 / 虚空兽 / 嗣骨拿玛 / 嗣骨以诺 / 以拿 / 嗣骨土八 / 约拿 / 该隐）。

## 安装

### 前置要求

- Rogue Legacy 2（Steam 正版或对应版本）
- [BepInEx 5.x](https://github.com/BepInEx/BepInEx)（Unity Mono 版本）已安装并能正常加载

### 步骤

1. 把以下两个文件放进游戏的 `BepInEx/plugins/` 目录：
   - `RL-Mod.dll`
   - `LiteNetLib.dll`
2. 启动游戏，BepInEx 控制台（或 `BepInEx/LogOutput.log`）出现 `[RL2MP] === Plugin Awake START (v1.6.1) ===` 即加载成功。
3. 首次运行会在 `BepInEx/config/` 生成 `com.rl2.mp.cfg`，里面有主机地址等配置（也可在游戏内面板修改）。

> **注意：所有玩家必须使用相同版本的 mod。** 协议格式随版本变化，新旧版本混用会连不上。

## 联机前的网络准备

本 mod 使用 **UDP 9050 端口** 直连，不经过任何服务器。按你的网络环境选一种：

| 方案 | 适用场景 | 说明 |
|------|----------|------|
| **同一局域网** | 同一 WiFi / 路由器下 | 主机直接填 `ipconfig` 里的内网 IP（192.168.x.x） |
| **Radmin VPN**（推荐） | 异地联机、没有公网 IP | 两边都装 Radmin VPN，加入同一个网络，主机填 Radmin 分配的虚拟 IP（通常是 26.x.x.x） |
| **ZeroTier** | 同上，备选 | 免费组虚拟局域网，主机填 10.x.x.x 虚拟 IP |
| **公网 IP + 端口映射** | 主机有公网 IP | 路由器把 UDP 9050 转发到主机，客机填主机公网 IP |

> Radmin VPN / ZeroTier 都**不需要**公网 IP、**不需要**做端口映射，装好 → 加网络 → 填虚拟 IP 即可。

**无论用哪种方案，主机都要放行防火墙**（Windows 常把虚拟网卡当"公用网络"拦截入站）：

```powershell
# 管理员权限运行
New-NetFirewallRule -DisplayName "RL2MP UDP 9050" -Direction Inbound -Protocol UDP -LocalPort 9050 -Action Allow
```

## 快速开始

### 主机（1 人）

1. 进入游戏，按 **小键盘 1 / F7** 打开控制面板。
2. （可选）检查面板里的网络设置。
3. 按 **小键盘 2** 或点「启动主机」——状态栏变为 `HOST (ID=0)`。
4. 正常开一局、进入世界。
5. 在面板「竞速」页选终点 Boss，调整赛制/数值（改动会实时广播给客机）。

### 客机（1~3 人）

1. 进入游戏，按 **小键盘 1 / F7** 打开面板。
2. 在「主机 IP 地址」填主机的 IP（虚拟 IP / 局域网 IP / 公网 IP），点「保存」。
3. 按 **小键盘 3** 或点「连接主机」——状态栏变为 `CLIENT (ID=1/2/3)` 并自动套用主机地图。
4. 主机选好终点后，进世界并点「我也准备好了」。
5. 全员就绪 + 全员在世界里 → 自动倒计时开跑。

### 开始后

- 跑图、杀怪、打 Boss；左上角 HUD 显示所有人的实时进度和名次。
- 竞速中死亡会**原地立即复活**（回满血 + 1.5 秒无敌），比用时模式还会加时。
- 有人完成后的宽限倒计时结束（或全员完成）→ 自动结算，显示名次表。

## 按键与面板

### 热键

| 按键 | 功能 |
|------|------|
| **小键盘 1 / F7** | 开关控制面板 |
| **小键盘 2** | 启动主机 |
| **小键盘 3** | 连接主机（用面板里保存的 IP） |
| **小键盘 4** | 停止网络（断开所有人） |
| **F9** | 测试：强制倒地（调试用） |
| **F10** | 测试：复活（调试用） |
| **F11** | 测试：把所有远程玩家标记为倒地（调试用） |
| **`[` / `]`** | 倒地观战时切换观战目标 |

### 控制面板

- **网络状态行**：当前角色（HOST/CLIENT）、玩家 ID、链路延迟（ms）；重连中会显示尝试次数与已用时。
- **主机 IP 地址**：客机连接目标，支持快速选择预设。
- **竞速页（主机专属设置）**：
  - 判定方式切换：**比用时** / **比得分**
  - 比用时模式：死亡加时调节（默认 60 秒/次，0~600）
  - 比得分模式：六项分值逐项调节（改动立即同步全员）
  - **完赛宽限**：第一名完成后其他人还能跑多久（默认 60 秒）
  - **重连宽限**：有人掉线后主机保留其槽位多久（默认 90 秒，15~300）
  - 终点 Boss 选择（8 选 1，立即广播）
- **大厅名单**：显示所有人的准备/在图/掉线状态，客机可点「我也准备好了」。
- **调试工具**（面板下方）：模拟远程玩家、倒地测试等。

## 两种赛制

### 比用时（Time）

- 先打死终点 Boss 者获胜。
- 每次死亡加时（默认 60 秒，可调），**加时直接计入最终成绩**：`最终成绩 = 净用时 + 死亡次数 × 加时`。
- HUD 实时显示每个人的当前用时 + 已死亡次数。

### 比得分（Score）

- 打死终点 Boss 即结束，比总分。
- 默认分值：

| 事件 | 分值 |
|------|------|
| 探索新房间 | +25 |
| 击杀普通怪物 | +3 |
| 击败 Boss | +300 |
| 拾取非任务遗物 | **-50** |
| 死亡一次 | **-100** |
| 每分钟自然衰减 | -20 |

- 同分时比完成用时；没人完成时按当前分数排。
- 主机在面板里改分值会立刻同步给所有客机。

## 断线与重连

- **客机掉线**：自动重连（退避 1→2→4→6 秒，最长尝试 45 秒）。重连成功后**恢复原玩家身份**，分数/用时/死亡数全部保留，HUD 状态行显示重连进度。
- **主机侧**：掉线玩家的槽位保留 **90 秒**（重连宽限，可调 15~300），期间他的成绩有效、名单显示「(掉线)」。
- 宽限超时：已完成的人成绩保留到本局结束；未完成的人标记 DNF 并移出名单。
- **主机自己掉线/崩溃**：目前不支持主机迁移，对局结束。客机的本地成绩仍在 HUD 上，重开房间即可。
- 主动按小键盘 4 断开不会触发自动重连。

## 常见问题排查

### 连接不上 / 卡在等待

1. 先确认主机防火墙放行了 UDP 9050（见上文命令）。
2. Radmin VPN / ZeroTier 里确认双方**互相授权/在线**，互相 ping 得通虚拟 IP。
3. 确认 `HostAddress` 填的是**虚拟/局域网 IP**，不是 127.0.0.1。
4. 确认两边 mod **版本一致**。
5. 看主机 BepInEx 日志有没有 `OnConnectionRequest`——没有说明包根本没到主机（网络问题）；有说明是 Key/版本不匹配。

### 客机能连上但看不到主机角色 / 地图不一致

- 查看客机日志里的 `[RL2MP] [MAP]` 行：应有「已套用主机地图」+ 地图验证通过。
- 若显示「游戏重建了世界」警告，让客机退回主菜单重新进世界。

### 延迟高 / 角色位置回跳

- 位置同步已做丢旧保新处理；仍严重时检查是否走了中继（ZeroTier 用 `zerotier-cli peers` 看是 DIRECT 还是 RELAY；Radmin 同理尽量直连）。
- 主机承载全部转发流量，主机上行带宽最好是最快的那条。

### 怪物数量异常 / 死后怪物复活 / 怪跨房间追人

v1.6.1 已修复（复活不再触发房间重新初始化）。若仍出现，确认所有客户端都是 v1.6.1 以上，并重开一局（旧局里已产生的异常怪无法回收）。

### 累赘 / NG+ 等级不一致

v1.0.1 起已自动同步：主机开新周目时会广播全部规则；客机内存覆写、退出会话后自动恢复，不会污染自己的存档。

## 已知限制

- **不支持主机迁移**：主机崩溃 = 对局结束。
- 怪物/宝箱/门的状态是**各自实例独立**的：布局一致，但 A 杀的怪 B 那边还在（只同步地图与规则，不同步世界实时状态）。
- 最多 4 人；第 5 个连接会被直接拒绝。
- 观战模式（非竞速死亡）会激活目标所在房间，复活后自动恢复，但镜头切换瞬间可能有轻微跳动。
- 反编译/修改存档相关逻辑有固有风险，mod 已做磁盘存档保护，但联机前仍建议备份存档。

## 构建方法

```
RL-Mod/
├── RL-Mod/            # mod 源码（老式 csproj，.NET Framework 4.7.2）
│   └── Libs/          # 引用：BepInEx / 0Harmony / Assembly-CSharp / LiteNetLib / UnityEngine
└── deploy/            # 发布产物
```

```bash
cd RL-Mod
dotnet build RL-Mod.csproj -v q -nologo
# 产物：bin/Debug/RL-Mod.dll
```

把 `bin/Debug/RL-Mod.dll` 和 `Libs/LiteNetLib.dll` 复制到游戏 `BepInEx/plugins/` 即可。新增源码文件需手动在 `RL-Mod.csproj` 里登记 `<Compile Include>`。
